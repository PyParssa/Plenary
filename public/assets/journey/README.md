# Journey images

Put your four initial-choice images in this folder with these exact names:

- `shoreline.jpg`
- `jungle.jpg`
- `sky.jpg`
- `forest.jpg`

The app tries these local files first and falls back to the current Unsplash images if a file is missing. JPG, PNG, or WebP are fine; if you use another extension, update the image path in `src/components/JourneyPicker.tsx`.
